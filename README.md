# Hair By Gabie G 🎄✂️

A Christmas browser game made for Gabie, Samantha's hairstylist, with love from Samantha & George.

**Play:** https://georgeconstablecreative.github.io/hair-by-gabie/

Designed for iPhone: open the link in Safari, then Share → **Add to Home Screen** to keep it like an app.

## What's inside
- **The story:** the panic call, pick the look, the cut, the wash, the blow-dry, the big reveal and a Christmas card
- **Gabie's Arcade:** Curler Catapult, Salon Invaders, Jingle Jam and Shampoo Swap

## Files
- `index.html`: the whole game in one file (no build step needed)
- `gabie-christmas-qr.png`: printable Christmas card with a QR code (app icon in the centre) that opens the game (print about 4×6 in)
- `gabie-christmas-qr-poster.png`: a light colour-block poster version of the QR card (MERRY XMAS tiles)
- `hair-by-gabie-qr-plain.png`: plain black-and-white QR code, the safest to scan when printed small
- `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `icon-1024.png`: the Christmas app icon (colour-block G, Santa hat, snowflake, scissors) used when it's saved to the Home Screen
- `manifest.webmanifest`: app name and icons for Add to Home Screen
- `.nojekyll`: tells GitHub Pages to serve the files as they are

## Publish with GitHub Pages
Settings → Pages → Build and deployment → Source: **Deploy from a branch** → Branch: **main** / **(root)** → Save.
